# Test fonctionnel KowSy — Création et suivi de dépenses

## 1. Ajout d’une dépense
- Ouvre la mini app KowSy > Suivi des dépenses
- Clique sur “Ajouter une dépense”
- Remplis :
  - Libellé : Courses
  - Montant : 5000
  - Catégorie : Alimentation
  - Date : aujourd’hui
- Clique “Ajouter”
- ✅ La dépense s’affiche dans la liste

## 2. Ajout d’une 2e dépense
- Clique “Ajouter une dépense”
- Libellé : Taxi
- Montant : 1500
- Catégorie : Transport
- Date : aujourd’hui
- Clique “Ajouter”
- ✅ Les deux dépenses sont listées

## 3. Vérification graphique
- Le graphique camembert affiche 2 parts (Alimentation, Transport)
- Les montants sont corrects

## 4. Dashboard
- Depuis l’accueil KowSy, clique “Tableau de bord”
- ✅ Le total des dépenses et le graphique sont corrects
- Les boutons d’accès rapide fonctionnent
